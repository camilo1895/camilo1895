# 👋 ¡Hola! Soy Camilo

Soy un desarrollador web **Full Stack** con formación en el bootcamp intensivo de **Soy Henry** y base técnica en **Programación de Software**.

💡 Me apasiona crear soluciones funcionales, aprender nuevas tecnologías y trabajar con buenas prácticas tanto en el backend como en el frontend. Mi enfoque principal está en tecnologías como **NestJS**, **TypeORM**, **PostgreSQL** y **Docker**.
